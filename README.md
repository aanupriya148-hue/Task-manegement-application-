# TaskBuddy – Task Management App

TaskBuddy is a simple and responsive task management application built using React and Vite.

## Features

- Add tasks
- Set task priority
- Select task category
- Mark tasks as completed
- Delete tasks
- Responsive user interface

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML
- CSS
